# Notebook Buddy — Brand Guide

**Version:** 1.0
**Last Updated:** 2026-07-06

> Single source of truth for anything visual in this project — logo, mascot, icons, colors, fonts, and how to generate new assets with AI without losing consistency.

---

## 1. Brand Essence

- **Personality:** Friendly · Supportive · Smart · Organized · Inspiring
- **Visual style:** Cute · Educational · Modern · Soft · Consistent
- **Mission:** Making learning organized, enjoyable, and achievable for everyone.
- **Tagline:** "Your learning companion"

---

## 2. Immutable Brand Rules

**Paste this first, before anything else, into any AI prompt.**

Never modify:
- Mascot proportions
- Notebook shape
- Glasses
- Bookmark
- Side tabs
- Spiral binding
- Outline thickness
- Brand Colors
- Typography & Wordmark Rules
- Illustration Style

Only ever change:
- Expression
- Pose
- Held object / small props
- Background Rules

**Never invent:**
- Extra accessories
- Additional colors
- A different notebook shape
- A different bookmark
- A different spiral binding
- Different glasses
- Different typography
- A different illustration style

---

## 3. Asset Creation Pipeline

**Canonical assets** (immutable — never recreate, only edit from the existing master file):
- `logo.png`
- `mascot.png`
- `wordmark.png`

**Derived assets** (always generated by image-editing with the relevant canonical file attached — never generated from text alone):
- `mascot-reading.png`, `mascot-thinking.png`, `mascot-celebrating.png`, `mascot-sleeping.png`, `mascot-search.png`, etc.

**Asset tiers** (work top to bottom, stop once "enough" for current needs):

| Tier | Assets | Precision needed |
|---|---|---|
| 1 | Logo, Wordmark, Mascot, App Icon, Favicon | Exact match — no AI regeneration, only resize/recolor |
| 2 | Expressions, Actions, Loading animations, Empty states | Image-edit from `mascot.png`, minor drift OK |
| 3 | Marketing graphics, Stickers, Badges, Seasonal graphics | Most flexible, lowest priority |

## 6. Theme System

Derive each theme by adjusting the base colors above — never regenerate the mascot from scratch for a new theme.

- **Light mode:** brighter background, same character colors
- **Dark mode:** navy/near-black background, same character colors, slightly boosted outline contrast
- **Comfort mode:** warm cream/tan background, muted accents

---

## 7. Typography & Wordmark Rules

- **Font:** Poppins (free on Google Fonts)
- **Weights used:** Bold, ExtraBold, SemiBold, Medium, Regular
- **Usage rule:** Headings → Bold/ExtraBold. Body/UI → Regular/Medium. Accent word ("Buddy") → SemiBold or Bold.

**Wordmark lock:**
- "Notebook" → color `#0F1F4E`, no gradient
- "Buddy" → gradient `#7C4DFF` → `#512DAB`
- Font: Poppins only

**Never:** change letter spacing, change font, curve the text, add undefined effects, change capitalization. Always preserve the approved spacing from `logo.png`.

---

## 8. Logo

- **Primary lockup:** Mascot icon + wordmark "Notebook" / "Buddy" + tagline underneath
- **Variants required:** Horizontal, Stacked, Icon-only
- **Master file:** `logo.png` — canonical; never regenerate via AI, only resize/recolor
- **Clear space:** Padding at least equal to the height of the mascot's glasses
- **Don'ts:** Don't stretch, don't recolor outside the palette, don't rotate, don't add undefined effects

## 9. Mascot — "Notebook Buddy" (Character Sheet)

Paste this block directly into any AI image generation/editing prompt, alongside the master reference image:

```
Character: Notebook Buddy — a cheerful anthropomorphic spiral notebook.
Body: Cream/warm-white notebook (#FFF9EE) with visible spiral binding on the left edge.
Face: Round brown glasses (#6A3E1E), simple dot or oval eyes, small friendly smile, rosy cheeks.
Accessories: Purple bookmark ribbon (#9B7BFF) sticking out of the top; colored side tabs in purple, orange (#FFB347), and red (#FF6868) along the right edge.
Limbs: Simple brown (#6A3E1E) stick-like arms and legs, no visible hand detail beyond a basic mitten shape.
Pose default: Standing, holding an open book/notebook in front with both hands, one arm sometimes raised in a wave.
Style: Flat vector/cute-cartoon illustration, soft rounded shapes, consistent outline weight, no photorealism, no gradients on the body (gradients allowed only in the wordmark).
Never change: glasses shape, body color, bookmark color/position, notebook spiral binding.
Acceptable to vary per asset: pose, expression, held object, background, small props.
```

- **Master mascot file:** `mascot.png` — always attach this as an image reference when generating new poses/expressions
- **Expression range (approved):** Curious, Reading, Thinking, Happy, Excited, Celebrating, Confused, Sleeping, Winking, Surprised, Laughing, Sad, Focused, Typing
- **Consistency rule:** Always use the approved `mascot.png` as the primary visual reference. Generate new mascot assets through image editing or reference-based generation whenever the tool supports it — avoid pure text-to-image.

## 10. Illustration Style

- Rounded geometry
- Soft lighting, soft shadows
- Minimal gradients (body stays flat; gradients reserved for wordmark only)
- Flat vector appearance
- Friendly, educational tone

**Never use:** anime style, realism/photorealism, sketch style, painterly textures, thick heavy outlines, watercolor, comic-book style.

---

## 11. Background Rules

| Asset type | Background |
|---|---|
| Logos | Always transparent |
| Mascot | Always transparent |
| Marketing graphics | May use gradients |
| Open Graph images | May use themed/solid backgrounds |
| Empty states | Simple, minimal backgrounds |

---

## 12. Camera Rules

**Default:** Front-facing, eye level, centered, no perspective distortion.

**Never:** fisheye effect, extreme close-up, cropped mascot (unless explicitly requested).

---

## 13. Lighting

- Soft diffuse lighting
- Warm highlights
- Minimal shadows

**Never:** dramatic lighting, rim lighting, colored lighting, harsh contrast.

---

## 14. Canvas

- Centered composition
- Transparent PNG
- Equal padding on all sides
- No clipping — entire mascot visible

---

## 15. Animation Rules

- Maintain identical proportions, colors, and outline across every frame
- Only change: limb position, facial expression, page position, accessory position
- Never redraw the mascot from scratch between frames

---

## 16. Icon System

- **Source:** Lucide icon set (free, open-source) — do not use AI-generated icons for UI
- **Style:** Outline + Filled variants, consistent stroke width
- **Theme variants:** Comfort / Light / Dark (same icon, recolored per the Theme System)

## 19. AI Workflow

1. Attach `mascot.png` (or `logo.png` as relevant).
2. Describe **one** modification.
3. Generate.
4. Review against the Validation Checklist.
5. Save only if approved.
6. If the output drifts from the canonical mascot, discard it and restart from `mascot.png` rather than correcting the drift through multiple edits.
7. Use the new image as the reference for the *next* edit only if it was approved.

**Never chain edits from an unapproved asset** — this is the single biggest source of gradual drift.

---

## 20. Prompt Rules

- Always attach `logo.png` or `mascot.png` — never rely on text description alone
- Prefer image-editing / image-reference mode over pure text-to-image
- Modify **one thing per generation**
- Review each output before generating the next asset
- Do not request multiple unrelated assets in a single prompt

---

## 21. Prompt Footer (Validation Checklist)

Every generated asset must satisfy:

- ✓ Same mascot
- ✓ Same colors
- ✓ Same proportions
- ✓ Same outline
- ✓ Same illustration style
- ✓ Transparent PNG
- ✓ Centered
- ✓ High resolution

---

## 22. Quick-Use Prompt Template

```
Using the attached reference image of Notebook Buddy exactly as the character design
(same glasses, body color #FFF9EE, bookmark #9B7BFF, outline #6A3E1E, tabs orange/red/purple),
generate a new pose: [DESCRIBE POSE/ACTION/EXPRESSION HERE].
Keep the art style, proportions, and colors identical to the reference.
Front-facing, eye level, centered, transparent background, flat vector cartoon style.
```
