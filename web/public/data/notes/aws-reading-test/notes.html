Why this note exists

This is a sample note written only for testing. It has long paragraphs, headings, a list, a table and a callout, so that every Reading Preferences setting has something obvious to change. Open Settings, change the font size, the line height, the font family and the content width, then come back to this page. The text you are reading right now should change; the rest of the app should not.

A second paragraph makes the line height easy to see. When the line height is small the lines sit tightly together, and when it is large there is a clear gap between them. The same paragraph also helps with the content width: a narrow width makes this text wrap into a short column, and a wide width lets each line run much longer across the page. Keep adjusting until you can see each setting working on its own.

  • First bullet: change the font size and watch this line grow or shrink.
  • Second bullet: change the font family and check the shape of the letters.
  • Third bullet: change the line height and compare the gap between lines.
  1. Step one: open the Settings page.
  2. Step two: find Reading Preferences.
  3. Step three: change one setting at a time and return to this note.
Setting What you should see
Font size Body text gets larger or smaller
Line height The gap between lines changes
Font family The letter shapes change
Width Lines wrap earlier or later

Only the note body changes. Headings in the app chrome, the Dashboard and Settings are not supposed to change. That is intended.

Key Takeaways:

  • Reading Preferences only affect the body text of a note.
  • Change one setting at a time so you can see what each one does.
